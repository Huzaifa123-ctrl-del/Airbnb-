# Airbnb Clone 🏠

A full-stack Airbnb clone built with Node.js, Express, MongoDB and EJS. Users can browse listings, add their own homes, and manage bookings.

**Live Demo:** https://airbnb-clone-beta-one.vercel.app/

### ✨ Features
- Browse all listed homes
- Add new home with image upload (Multer)
- User Authentication (Login / Signup)
- Host Dashboard - Add / Delete Homes
- Favourites System
- Responsive Design

### 🛠️ Tech Stack
- **Frontend:** EJS, Tailwind CSS / CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas + Mongoose
- **File Upload:** Multer (Vercel /tmp compatible)
- **Deployment:** Vercel
